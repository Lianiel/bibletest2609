# 2026年9月每日活水聖經複習測驗

這是獨立的 2026 年 9 月測驗，不整合、不修改 3～8 月題庫與歷史資料，也不連接既有 Puhe 主程式。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可使用。題庫共100題，每次抽50題；測驗採一次一題顯示，選擇答案後立即顯示對錯、鎖定選項並按「下一題」，最後一題才交卷。同一次不重複，跨次優先抽取本輪尚未出現的題目，完成一輪後再重新開始。

## 資料來源

`questions.js` 由使用者提供並確認的 Q001～Q100 轉換而成，題目、選項、答案與經文出處未重新出題或改寫。輪替紀錄保存在瀏覽器的 localStorage，鍵名為 `daily-water-quiz-202609-v1`。

本階段只建立與測試獨立測驗，未部署、未發布、未修改正式程式。
